# Catálogo único de requisitos (RF y RNF)

> Fuente única de identificadores. HU, CA y matriz de trazabilidad deben citar **solo** estos IDs. Normalizado en SCRUM-196.

## Convención

- `RF-NNN`: requisito funcional. `RNF-NNN`: requisito no funcional. `CA-NNN`: criterio de aceptación. `HU-NN`: historia de usuario.
- Los IDs no se reutilizan ni se renumeran. Un requisito eliminado se marca como *retirado*; uno nuevo toma el siguiente número libre.
- La relación CA → requisito se define aquí (columna *CA*). La columna *HU* se deriva de los CA de cada historia.
- Numeraciones anteriores: ver [equivalencias-ids.md](equivalencias-ids.md).
